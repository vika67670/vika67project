# Random Password Generator

## Автор

Петрова Виктория Игоревна

## Описание

Данный проект представляет собой GUI-приложение для генерации случайных паролей.

Функционал приложения:

* Настройка длины пароля с помощью ползунка
* Выбор типов символов:

  * цифры
  * буквы
  * специальные символы
* Генерация случайного пароля
* Сохранение истории сгенерированных паролей
* Загрузка истории из JSON-файла

Программа использует стандартную библиотеку Python `random` для генерации паролей.

## Установка и запуск

1. Убедитесь, что у вас установлен Python (версия 3.x)
2. Склонируйте репозиторий:

```
git clone https://github.com/your-username/random-password-generator.git
```

3. скинь файл Перейдите в папку проекта:

```
cd random-password-generator
```

4. Запустите файл:

```
python main.py
```

## Использование

1. Выберите длину пароля с помощью ползунка
2. Отметьте необходимые типы символов (буквы, цифры, спецсимволы)
3. Нажмите кнопку "Сгенерировать"
4. Скопируйте полученный пароль
5. История паролей автоматически сохраняется

## Проверка корректности

* Минимальная длина пароля ограничена
* Максимальная длина пароля ограничена
* Проверяется выбор хотя бы одного типа символов

## Пример

Пример сгенерированного пароля:

```
A9#kL2!xQ
```

## Дополнительно

История паролей сохраняется в файл `history.json` и загружается при повторном запуске приложения.
